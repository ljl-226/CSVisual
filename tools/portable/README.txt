CSVisual 计算机可视化智能学习平台 — 使用说明
================================================================

【怎么启动】

  双击本目录下的 start.bat。
  （如果是用安装包装的，也可以点桌面或开始菜单里的「CSVisual」）

  第一次启动会自动做三件事（约 2 分钟，之后每次只要几秒）：
    1. 初始化内置数据库（data\mysql）
    2. 导入课程、题库、知识点等演示数据（initdb\cs_visual.sql）
    3. 生成 app\server-py\.env 配置文件

  跑起来后浏览器会自动打开 http://127.0.0.1:3000
  没自动打开就手动访问这个地址。

【怎么停止】

  运行「停止 CSVisual」快捷方式（或安装目录下的 stop.bat）。
  直接关掉命令行窗口不会结束后台的数据库进程，一定要走 stop.bat。

【端口】

  网站   3000
  数据库 3307   —— 特意避开 3306，不会和你自己装的 MySQL 抢端口

  如果 3000 被别的软件占了，改 app\server-py\.env 里的 PORT 再重新启动。

【目录说明】

  app\server-py   后端源码（Python + FastAPI）
  app\web         前端页面（构建产物）
  runtime\python  内置 Python 3.13 运行时（含后端依赖）
  runtime\mysql   内置 MySQL 8.0.34（已精简，只留运行必需的组件）
  data\mysql      数据库文件（第一次启动后才有）
  initdb          初始化用的 SQL

  本机不需要另外安装 Python / MySQL，运行时全都自带。

【关于编译运行】

  Python / JavaScript 的程序由内置的 Python 直接执行，完全离线可用。

  C / C++ / Java 的编译器没有随包分发（完整工具链连同头文件静态库约 467 MB，
  塞进来的话安装包会从 69 MB 涨到三百兆以上），平台按下面三条路径依次尝试：

    ① 本机已经装过编译器（Dev-C++ / VS / IDEA / JDK 等）
       —— 后端扫描十余个常见安装位并真实编译 hello world 验证后直接用，最快；
    ② 没有就自动转「云端沙箱」编译运行
       —— 需要联网，一次约 10~70 秒，结果的正确性和本地完全一样，
          控制台会标注「云端沙箱」；
    ③ 想长期在本机编译（比云端快约 10 倍、可离线）
       —— 在本机装好 Python 后，从源码包里取 tools\setup-runtime.bat
          放在本目录下双击执行一次即可把编译器装进 runtime\。

  也就是说：这台电脑上从来没装过编译器，也能跑出真实结果；
  断网场景下 Python / JavaScript 照常运行，C/C++/Java 需先做上面的 ③。

【关于绿色版】

  整个目录是自包含的：不写注册表、不在系统里留任何东西，
  可以直接拷到 U 盘或另一台电脑上继续用（拷之前先运行 stop.bat）。
  不用了就把整个目录删掉，干净利落。

【常见问题】

1. 启动卡在「正在初始化数据库」超过 2 分钟
   看 data\init.log 里的报错。最常见是杀毒软件拦截 mysqld.exe，
   把安装目录加到杀软白名单后重试。

2. 提示端口被占用
   先运行「停止 CSVisual」，再启动。仍不行就重启电脑。

3. 想清空所有数据恢复初始状态
   停止服务 → 删掉 data 整个目录 → 重新运行 start.bat
   （会重新初始化并导入全部演示数据）

4. AI 答疑没有回答 / 回答比较基础
   没配置大模型 Key 时会自动降级为「本地知识库检索」，离线也能演示。
   想接真的大模型：改 app\server-py\.env 里的 LLM_API_KEY。

5. 卸载 / 删除
   绿色版：先运行 stop.bat 停止服务，然后直接删掉整个目录即可。
   安装版：用 Windows 的「添加或删除程序」卸载 CSVisual。
   两种方式的数据库文件都在 data\mysql 里，删掉目录即彻底清除。
